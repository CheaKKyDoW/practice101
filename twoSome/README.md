# Two Sum

Find two elements in the given array that sum up to the given target.

**Input:**

* `nums`: an array of integers
* `target`: an integer

**Output:**

* an array of two indices. The elements at these indices in `nums` sum up to `target`.

**Example:**

* `nums = [2, 7, 11, 15]`
* `target = 9`
* Output: `[0, 1]` because `nums[0] + nums[1] = 2 + 7 = 9`

**Constraints:**

* Assume that there is always a solution.
* Do not use the same element twice.
